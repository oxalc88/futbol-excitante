# Project-local OpenCode config

This directory is part of the `pes-simulator` git repository.

It is **not** global OpenCode config. Do not copy these agents to `~/.config/opencode/agents/` or install them through oxStack.

| Path | Role |
|---|---|
| `agents/` | Gauntlet primary and subagent prompts |
| `commands/gauntlet.md` | `/gauntlet` launch command |

Model IDs and `default_agent` live in the repo-root `opencode.json`.
